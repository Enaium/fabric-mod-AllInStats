# AllInStats 全部统计

![](https://img.cdn1.vip/i/6ab93461f192d_1790522465.webp)

一个记录世界内实际发生的事情并以图表展示的 Fabric 模组。

原版统计不够详细：它无法回答"昨天我拾取了哪些物品"、"其中多少是钓鱼获得的"、"刷怪农场击杀了
哪些生物"、"这一周我用坏了几把镐子"。AllInStats 按世界和玩家记录每一项统计，保留分钟级的
历史数据，并在 ImGui 界面中绘制成可缩放、可导出的图表。

## 功能

记录的统计项（按世界、按玩家分别记录）：

| 大分类 | 统计项 |
|---|---|
| 物品 | 获取（区分来源：拾取、合成、容器、钓鱼）、丢弃 |
| 方块 | 破坏、放置 |
| 生物 | 被玩家击杀、玩家被生物击杀 |
| 工具 | 耐久消耗、损坏 |

界面（暂停菜单的统计按钮进入本模组界面，界面内也能再次打开原版统计界面）：

* 大分类（物品、方块、生物、工具、钓鱼）与细分类（石头、泥土、猪……），显示总量、可搜索、可排序
* 可同时多选细分类（最多 8 项），每个条目的统计在同一张图中各显示为一条系列；只有单个条目时
  才提供 K 线
* 图表类型：折线图、面积图、柱状图、散点图、K 线
* 颗粒度：分钟、小时、天、周、月、年
* 时间区间：自定义起始与结束时间（格式 `yyyy-MM-dd HH:mm`，输入框内显示格式提示，无法解析时给出
  提示），可用按钮按小时/天前后移动区间，以及最近 1 小时/1 天/7 天/30 天/1 年/全部 预设
* 按统计项分系列，单个物品条目还可按来源分系列
* 滚轮缩放、拖动平移、双击自适应、重置缩放；任何缩放级别下时间轴都显示为时间，光标读数也显示时间
* 界面打开期间每 2 秒自动重新读取统计（可关闭），且打开界面时会立即写入并读取，刚记录的数据
  无需重新打开界面即可看到
* 将当前可见区间导出为 CSV（每个系列一列）或 PNG
* 物体名称使用游戏语言显示，界面本身支持中文和英文；界面使用系统字体以正确渲染对应语言，且该
  字体只用于本模组的窗口，其他模组的窗口仍使用游戏默认字体

## 安装

服务端（负责记录）需要安装本模组。单人游戏由内置服务端记录，无需额外操作。

依赖：

* Fabric Loader
* [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin)
* [fabric-gui-imgui](https://modrinth.com/mod/fabric-gui-imgui)（ImGui 与 ImPlot 界面）
* [fabric-orm-jimmer](https://modrinth.com/mod/fabric-orm-jimmer)（Jimmer ORM）
* [fabric-database-h2](https://modrinth.com/mod/fabric-database-h2)（H2 数据库）

多人游戏中记录的是服务器的数据库；客户端的界面只能读取自己游戏目录中的数据库。

## 数据

* 数据库：`<游戏目录>/allinstats/stats.mv.db`（H2，一个安装目录一个文件，每个存档、每个玩家
  分别存储）
* 导出目录：`<游戏目录>/allinstats/exports`
* 统计先缓存在内存中，每 2 秒写入一次，游戏运行时不会等待数据库；打开界面时会先把内存中的统计
  写入数据库再读取，因此不会看到过期数据。强制结束游戏可能丢失最后几秒的统计。

```
stat_world   (id, world_id, name, created_time, modified_time)
stat_player  (id, world_id, uuid, name, created_time, modified_time)
stat_counter (id, world_id, player_uuid, type, stat_key, source, bucket, amount)
```

`bucket` 是该分钟对应的毫秒时间戳，`type` 是统计项，`stat_key` 是对象的注册名
（`minecraft:stone`），`source` 是物品来源。界面中的所有颗粒度都由这些分钟数据聚合得到。

## 已知限制

* 所有统计都由服务端记录，因此数据在服务端（单人游戏为内置服务端）。多人游戏中客户端只能读取
  自己游戏目录中的数据库，数据不会通过网络传输。
* 导出图像是由 JVM 自身的图形工具（无窗口模式，macOS 上强制开启，因为主线程被游戏占用）绘制的
  同一份数据与系列，而不是 ImGui 窗口的截图。
* K 线由区间内的分钟级统计聚合而成，因此最多读取所选区间中最近 120 天的数据。
* 1.12.2 及更早版本中，钓鱼收获取自浮标的掉落判定而不是进度触发器；物品被拾取时会再记录一次
  （与其他版本一致）。
